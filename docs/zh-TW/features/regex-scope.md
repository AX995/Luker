# 正則規則作用範圍

一條正則規則可以應用在多個位置。正則編輯器將選擇拆分為兩組，兩組內的選項可以自由組合在同一條規則上。

## 影響條目

「影響條目」決定規則處理哪些內容。

- 「使用者輸入」「AI 輸出」「斜線命令」「世界資訊」「思考」將規則收窄到對應類型的訊息。規則僅對屬於已勾選位置的訊息生效；未勾選任何位置時，規則僅會被儲存，不會被執行。
- 「插件訊息」使規則處理外掛請求的往來文字：進入外掛請求的文字，包括聊天樓層文字、外掛拼寫的訊息、世界資訊條目；以及外掛請求回傳的助手正文。
- 「最小深度」與「最大深度」按照訊息在聊天中的位置過濾規則處理的訊息。

## 其他選項 → 暫時性

「暫時性」決定規則是否僅作用於某一份文字而不改寫聊天檔案。

- 「僅修改聊天顯示」——規則改寫聊天介面顯示的內容。
- 「僅修改系統提示詞」——規則改寫主聊天傳送給模型的提示詞。
- 均未勾選時，規則在訊息編輯或儲存時直接改寫聊天檔案。

## 說明

- 正文中自訂的 CoT 標籤需要清除時，不勾選「暫時性」內的選項即可：規則僅改寫一次儲存的訊息，聊天顯示、傳送給模型的提示詞、外掛請求讀取到的均為清理後的文字。
- 清除自訂的 CoT 標籤時同時勾選「僅修改聊天顯示」與「僅修改系統提示詞」，只會帶來效能開銷。
- 自訂的 CoT 標籤需要保留為可摺疊區塊時，使用「進階格式化」→「推理格式」。
