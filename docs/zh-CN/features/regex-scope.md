# 正则规则作用范围

一条正则规则可以应用在多个位置。正则编辑器将选择拆分为两组，两组内的选项可以自由组合在同一条规则上。

## 作用范围

「作用范围」决定规则处理哪些内容。

- 「用户输入」「AI输出」「快捷命令」「世界信息」「思考」将规则收窄到对应类型的消息。规则仅对属于已勾选位置的消息生效；未勾选任何位置时，规则仅被保存，不会被执行。
- 「插件消息」使规则处理插件请求的往来文本：进入插件请求的文本，包括聊天楼层文本、插件拼写的消息、世界信息条目；以及插件请求返回的助手正文。
- 「最小深度」与「最大深度」按照消息在聊天中的位置过滤规则处理的消息。

## 其他选项 → 短暂

「短暂」决定规则是否仅作用于某一份文本而不改写聊天文件。

- 「仅格式显示」——规则改写聊天界面显示的内容。
- 「仅格式提示词」——规则改写主聊天发送给模型的提示词。
- 均未勾选时，规则在消息编辑或保存时直接改写聊天文件。

## 说明

- 正文中自定义的 CoT 标签需要清除时，不勾选「短暂」内的选项即可：规则仅改写一次存储的消息，聊天显示、发送给模型的提示词、插件请求读取到的均为清理后的文本。
- 清除自定义的 CoT 标签时同时勾选「仅格式显示」与「仅格式提示词」，只会带来性能开销。
- 自定义的 CoT 标签需要保留为可折叠区块时，使用「高级格式化设置」→「推理内容格式化」。
